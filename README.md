## Features

- **3 ATS-friendly templates** — Default, Operator, Highlight
- **Live preview** — see your resume update as you type
- **Sample content** — starts filled in, clears the moment you type
- **Drag-and-drop reordering** — for sections, experience, and skills
- **Resume score** — flags weak spots before you export
- **Writing assistant** — built-in phrase suggestions
- **Guided tour** — quick walkthrough on first visit
- **One-click PDF export** — clean A4 output
- **Fully accessible** — keyboard-friendly, zero `axe-core` violations
